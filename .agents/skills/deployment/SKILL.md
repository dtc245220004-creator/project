**Đầu vào:** Cấu trúc dự án và mã nguồn hoàn chỉnh.
**Đầu ra:** File `requirements.txt` và `README.md`.

**Quy trình:**
1. Xuất danh sách thư viện ra `requirements.txt`.
2. Tạo file `README.md` mô tả dự án và hướng dẫn khởi chạy.
3. Thực hiện commit Git cuối cùng kết thúc SDLC.
